# RackWatch Logo Pack v1.0

Approved identity: 16 August 2026

## Contents

- `SVG/`: production vector artwork with all lettering converted to paths.
- `PNG/`: transparent-background raster exports for everyday use.

## Official lock-ups

- **Primary:** appliance icon plus `RackWatch`.
- **Marketing:** primary lock-up plus `Confidence at a glance`.
- **Icon:** appliance symbol alone for favicons, app/interface use, stickers and merchandise.

The wordmark position never moves when the tagline is added. The wordmark bottom aligns with the bottom of the lower rack unit.

## State colours

- Healthy: `#00D95A`
- Degraded: `#F4B400`
- Fault: `#FF3B3B`
- Unknown / booting: `#6F777C`

## Core colours

- Dark operational background / aperture: `#101215`
- Appliance body: `#292E32`
- Dark-background wordmark: `#F4F3EF`
- Light-background wordmark: `#111416`
- Dark-background tagline: `#747B7F`

## Usage rules

1. The inset circular aperture is the only state-changing element.
2. Do not recolour the wordmark to indicate state.
3. Use the tagline only where it remains comfortably legible.
4. The tagline is sentence case, darker than the wordmark, left-aligned and never longer than the wordmark.
5. Do not move the wordmark when adding or removing the tagline.
6. Use the monochrome version for engraving, embroidery, vinyl cutting and single-colour production.
7. Preserve clear space around the logo equal to at least half the appliance icon's height.

## Typography

The approved wordmark was constructed from DejaVu Sans Regular and converted to outlines in every production SVG. No font installation is required to use the supplied artwork.
