# RackWatch Documentation Workspace

This repository is the working source for the RackWatch developer documentation pack.

## Current controlled documents

- `RWS-001/` — RackWatch Engineering Specification, Revision 1.0, Developer Issue
- `RWS-002/` — RackWatch Technical Specification, Revision 1.0, Developer Issue

## Working method

Each specification is maintained as a set of Markdown chapters. These files are the persistent engineering source. Word/PDF issue copies are generated from this source once the content is stable.

The repository exists to prevent engineering decisions becoming trapped in chat history. New decisions should be incorporated into the relevant chapter rather than recreated later.

## Source lineage

RWS-001 is derived from the reviewed Engineering Specification v0.7 and incorporates the agreed review changes, including a vendor-neutral adapter model and SNMP as a baseline monitoring source.

RWS-002 is derived from the RackWatch Tech Summary v0.9 and consolidates the current hardware, security, licensing and commercial architecture.

## Status

Both documents are being prepared as **Revision 1.0 — Developer Issue** for external developer scoping and quotation.
